an.audio.recorded#

Recorded voices: a performer’s takes as the voice of a character (an#490).

A production that records its actors has the voices already; nothing should be synthesized, billed, or approximated. This module makes a recording a first-class input, through the seams the audio pipeline already has:

  • The take is a voice. RecordedTTS is a TTSProvider named recorded whose “synthesis” is a lookup in the project’s recordings store (RecordingsStore). A voice document that declares provider: recorded is spoken by it (an#305), so takes, effects, leveling, captions, the shot cache and an render work unchanged, and nothing is billed: the provider declares billed = False and repeatable = True. Its synthesis_options hook keys each line by the digest of the take it has for it, so a re-recorded line is a new audio key, never a stale cache hit.

  • The words travel with the clip. A take imported with a timed transcript (or transcribed) knows its word timings; they are stored with it, handed to the pipeline on words, and a lip-sync provider that aligns from words (cutan’s) uses them instead of its own transcription — the mouth follows the performance.

  • Import (import_recordings(), an voices import): one or more audio files — a whole take with several lines, or one file per line — with an optional transcript (SRT, WebVTT, TextGrid, word JSON or plain text: an.audio.transcripts). Each line of the recording is cut out, matched

    to the scene’s dialogue by its words (a line the scene does not have yet is added to the shot you name), and stored with its provenance: who recorded it, under which licence or permission, from which file and span. The speaker’s character is bound to the recorded voice; the gap heard between two lines becomes the next line’s pause, so the shot’s timing follows the recording.

Seams, each one keyword argument of import_recordings():

  • transcribe: a callable path -> segments for a take that comes with no timed transcript; the default is scribed’s facade (pip install "an[recorded]", then a backend of your choice — words and, where the backend has it, speakers). Not needed for one file per line or a timed transcript: those paths run with no model at all.

  • denoise: off; a strategy name runs the matching ffmpeg filter (DENOISE_FILTERS) before anything else; voxy.refprep.condition is the fuller conditioning when you want more.

  • Speaker attribution: speaker (one performer), speakers (a label → character map, for a diarizer’s or a transcript’s labels and file stems), the transcript’s own speaker: prefixes, the file’s stem, or the scene line the words match.

>>> from an.audio.tts import AudioClip
>>> tts = RecordedTTS()
>>> tts.name, tts.billed, tts.repeatable
('recorded', False, True)
>>> normalize_key_text("Hello, there!") == normalize_key_text("hello there")
True

The recorded TTS provider: a line’s audio is the take imported for it.

Built by an.audio.providers.make_tts() with the project mall, so it reads mall["recordings"]; the pipeline hands it each line’s text and voice through synthesis_options() (which keys the line by its take’s digest) and synthesize(). A line with no take raises RecordingMissingError before anything else is touched — a recorded voice never falls back to a synthesized one.

an.audio.recorded.import_recordings(project, audio, *, transcript=None, speaker=None, speakers=None, shot=None, voice=None, denoise=None, license=None, recorded_by=None, transcribe=None, transcriber=None, diarize=False, match_threshold=0.75, write=True)[source]#

Import a performer’s recording(s) as the voice of their lines (an#490).

audio names the takes (a file, several, a directory, a glob): a whole take holding several lines, or one file per line. transcript is optional: SRT, WebVTT, TextGrid or word JSON time the lines so nothing is transcribed; a plain transcript (speaker: text lines) pairs one line per file, or is timed against transcribe’s words for a whole take; with no transcript at all the take is transcribed and its segments are the lines.

Each line is cut out, matched to the scene’s dialogue by its words (match_threshold), stored in mall["recordings"] with its provenance (license is required: the code you vouch for; recorded_by names the performer), and the speaker’s character is bound to a recorded voice document (voice, default <speaker>_recorded). Takes matching no line are added to shot (or the first shot of a scene with no dialogue). The gap heard between two lines of one file becomes the later line’s pause.

denoise ("afftdn" / "anlmdn") cleans each file first, through ffmpeg. transcribe is the transcriber seam (path -> segments); its default is scribed_transcriber() with transcriber as the backend and diarize for speaker labels, built only when a take needs it. write=False runs everything but writes nothing (a dry run).

ImportReport
