an.audio.voice_design#

Design a project’s voices from their written notes, then let the writer choose.

A voice document (assets/voices/<ref>.json) may carry the voice in words: notes (age, accent, pitch, pace, attitude) and, optionally, sample_text (what the samples say). Voice design turns those words into candidate voices the writer can LISTEN to, and the writer’s choice becomes the document’s voice_id. That is how a regional accent gets cast by the one person who can hear it (a local ear for a local accent), with nobody else picking from a stock library.

Two steps, both plain functions over injected stores:

  • design_voice_options(): per voice, ask a designer for previews of its notes speaking its sample text, store each preview’s audio in samples and return the options manifest ({ref: {"notes", "sample_text", "design_model", "options": [{"option": "A", "generated_voice_id", "voice_id", "sample", "duration_s"}]}}). With persist=True (the default) every preview is saved as a durable provider voice at once, because a provider’s previews expire; with persist=False only the chosen one is, later (fewer voices in the account, but a choice must come before the previews expire).

  • choose_voice_option(): the voice_id of the chosen option (saving it as a voice first when it was not persisted).

A choice is recorded, and a render needs one (an#486). A voice written in words (notes) is cast by the writer, nobody else: an voices choose writes chosen_by and chosen_at beside the voice_id (record_choice()), and a voice document that has notes but no recorded choice is a render finding, refused under --strict-assets before anything is synthesized (voice_casting_problem()). A timing draft may speak a stand-in voice only with an explicit provisional (true, or a string saying why), which every render report lists.

The project-level forms, design_project_voices() and choose_project_voice(), keep the manifest in artifacts/voice_options/<ref>.json, the samples in artifacts/voice_samples/<ref>_<option>.mp3, and write the chosen voice_id (and provider) into the voice document. an voices design and an voices choose are their CLI.

The designer is a seam (designer=): by default ElevenLabsVoiceDesigner (ElevenLabs Voice Design through the elevenlabs SDK an’s ElevenLabs TTS already uses; key in ELEVEN_API_KEY). voxy’s ElevenLabsSpeechModel is a drop-in (designer=voxy.get_speech_model("elevenlabs")), not the default because voxy brings torch. Anything with these two methods works:

design_voice_previews(description, *, text, model_id) -> [preview]   # preview.generated_voice_id, .audio, .duration_s
design_voice(description, *, preview, name) -> profile                # profile.segment is the voice id

Designing is billed by the provider; nothing here is called by a render.

>>> class Fake:
...     def design_voice_previews(self, description, *, text=None, model_id=None):
...         from types import SimpleNamespace as N
...         return [N(generated_voice_id=f"g{i}", audio=b"ID3", duration_s=1.0) for i in range(2)]
...     def design_voice(self, description, *, preview, name):
...         from types import SimpleNamespace as N
...         return N(segment="v-" + getattr(preview, "generated_voice_id", preview))
>>> samples = {}
>>> notes = "A man in his fifties from rural Yorkshire, warm and unhurried."
>>> manifest = design_voice_options({"jerry": {"notes": notes}}, samples=samples, designer=Fake())
>>> [(o["option"], o["voice_id"], o["sample"]) for o in manifest["jerry"]["options"]]
[('A', 'v-g0', 'jerry_A'), ('B', 'v-g1', 'jerry_B')]
>>> sorted(samples)
['jerry_A', 'jerry_B']
>>> choose_voice_option(manifest["jerry"], "B", designer=Fake())
'v-g1'

an.audio.voice_design.voice_casting(voice_refs, voices)[source]#

(uncast, provisional): one message per distinct voice of voice_refs (the voices a scene’s lines speak with) that a render must not speak as it stands, and one per voice it speaks provisionally. Each message starts with voice '<ref>' and the uncast ones name the fix.

>>> voices = {"j": {"notes": "n", "voice_id": "v"}, "p": {"notes": "n", "voice_id": "v",
...           "provisional": "round-2 timing draft"}, "k": {"voice_id": "x"}}
>>> uncast, provisional = voice_casting(["j", "p", "k", "j", "ghost"], voices)
>>> print(uncast[0])
voice 'j' has a voice_id nobody is recorded as choosing (no chosen_by). Cast it: `an voices design` (options from its notes) then `an voices choose <option> --by <writer>` (the pick, recorded as chosen_by), or `an voices cast <voice_id> --by <writer>` for a voice picked by hand (`an voices list`); a timing draft may set `provisional: true` on the voice document instead.
>>> provisional
["voice 'p' is provisional (round-2 timing draft): choose a voice before the cut"]
Return type:

tuple[list[str], list[str]]

an.audio.voice_design.voice_casting_problem(doc)[source]#

Why a render must not speak doc as it stands, or None.

A voice written in words (notes) is cast only once a choice is recorded (chosen_by beside the voice_id), or it is marked provisional. A document without notes names its voice by hand and is not judged here.

>>> voice_casting_problem({"voice_id": "v1"}) is None
True
>>> print(voice_casting_problem({"notes": "a warm voice"}))
is written in words but no voice is chosen for it: nothing to speak with
>>> print(voice_casting_problem({"notes": "a warm voice", "voice_id": "v1"}))
has a voice_id nobody is recorded as choosing (no chosen_by)
>>> voice_casting_problem({"notes": "n", "voice_id": "v1", "chosen_by": "noel"}) is None
True
>>> voice_casting_problem({"notes": "n", "voice_id": "v1", "provisional": "draft"}) is None
True
>>> voice_casting_problem({"notes": "n", "provisional": True}) is None  # provisional WHAT?
False
