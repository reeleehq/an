an.music_library#

Acquire a licensed music library, with provenance: an’s bridge to foley (an#470, an#656).

The library itself lives in foley (foley.sources.music_library): the registry (incompetech, and the paid artlist and epidemic_sound, whose titles become wishlist rows), the direct and Wayback mirrors, the polite fetch with 429 / Retry-After resilience, the audio probe, the licence gate, the tracks table and the credit parser. an music add-library (an.music_cli) is its command:

an music add-library incompetech –titles-from usage.json –out audio/macleod

What stays here is what is an’s:

  • asset_source(), the bridge: one foley row (an AcquiredTrack, or its .row() read

    back from a tracks table) as an an.ir.assets.AssetSource, the provenance a sound in the project’s store carries. foley’s licence ids become an’s codes (license_code(): CC-BY-4.0 is cc-by-4.0; foley’s unknown, a paid library’s, is None, which an reads as UNKNOWN); the library’s own address is source_page_url; rights_verified, the mirror and a titles file’s metadata ride as extras.

  • acquire(), foley’s with an’s pause knob (seconds before a second request to one host), which becomes foley’s per-host rate.

The rest of foley’s surface the command and its tests use (MUSIC_LIBRARIES, tracks_table(), attribution_text(), titles_by_library(), …) is re-exported by name, and loaded on first use: import an never imports foley.

>>> license_code("CC-BY-4.0"), license_code("unknown")
('cc-by-4.0', None)
>>> src = asset_source({"title": "Sneaky Snitch", "library": "incompetech",
...                     "status": "acquired", "license": "CC-BY-4.0",
...                     "source_page_url": "https://incompetech.com/x.mp3",
...                     "rights_verified": True, "mirror": "wayback"})
>>> src.provider, src.id, src.license, src.source_page_url
('incompetech', 'Sneaky Snitch', 'cc-by-4.0', 'https://incompetech.com/x.mp3')
>>> src.model_extra
{'rights_verified': True, 'mirror': 'wayback'}

foley’s acquire(), paced by pause.

pause is the seconds before a second request to one host (0: no pause), foley’s rate unless config states its own. config and every other keyword (fetch, mirrors, verify, kept, intended_use, clock, sleep, …) go to foley as they are. Bridge the rows with asset_source().

Raises:

an.music_library.asset_source(track, *, codes={'unknown': None})[source]#

One foley row as an’s AssetSource.

track is a foley AcquiredTrack or its .row() (as a tracks table reads back). library is the provider, title the id, the licence id an’s code (license_code()); url (the mirror that served the bytes), source_page_url (the library’s own address), the licence URL, author, attribution and sha256 keep their names. The acquisition’s own columns (ROW_ONLY) stay in the table; every other column (rights_verified, commercial_ok, mirror, credited_by, a titles file’s metadata) rides as an extra; a licence flag read back from CSV (FLAG_COLUMNS) is a boolean again. Empty cells are dropped. A track also gives its licence’s creator_url as author_url and whether its terms let the bytes be kept as cacheable.

Return type:

AssetSource

The attribution blocks to paste under a video, one per track that has one (acquired or kept), blank-line separated, each once.

an.music_library.register_music_library(library, *, replace=False)[source]#

Add library to MUSIC_LIBRARIES (replace to redefine one).

A free library is checked for one licence right only, keeping the files (cache_bytes_ok); the uses a production makes of them are gated per title by acquire() (intended_use).

A library’s name is also its live-source name (foley.add_from(name, ...)), so it may not be the name of a source another foley.sources module declares, or one registered directly (openverse, freesound, a fal_* endpoint, …): that library would silently take the source over, or silently never become one.

Raises:

  • MusicLibraryError – If the name is taken (and not replace), or a free library has no track_url rule or a licence that does not allow keeping the files (a ShareAlike / NoDerivatives licence, refused on purpose; a licence URL foley cannot read; a licence whose flags say no).

  • SourceNameCollision – If the name is another module’s source name.

Return type:

None

an.music_library.titles_by_library(description, *, libraries=None)[source]#

The titles a video description credits, by library (default: the registered ones).

A line naming a library (by name or alias, with From/Music by/ Music: and a parenthetical allowed around it) opens its block, and each following line is a title until a blank line; a timestamp, a Song:/Track: label, quotes and bullets are stripped, and links and licence lines skipped. The attribution form ("Title" Kevin MacLeod (incompetech.com)) credits its title wherever it stands.

>>> text = '''Music:
... From Epidemic Sound:
... - 0:00 Night Owl
... - Song: "Morning Light"
... https://www.epidemicsound.com/
...
... "Sneaky Snitch" Kevin MacLeod (incompetech.com)
... Licensed under Creative Commons: By Attribution 4.0 License'''
>>> titles_by_library(text)
{'epidemic_sound': ['Night Owl', 'Morning Light'], 'incompetech': ['Sneaky Snitch']}
Return type:

dict[str, list[str]]
