- **One changelog fragment per PR** (an#469): a PR adds `misc/changelog.d/<YYYY-MM-DD>-an<issue>-<slug>.md` (one `- ` entry) instead of editing `misc/CHANGELOG.md`, so parallel PRs stop conflicting on the same date's lines; `python misc/changelog.py render` reads the changelog with them in place, `fold` (a maintainer, from the default branch) writes them into `misc/CHANGELOG.md` and deletes them.
