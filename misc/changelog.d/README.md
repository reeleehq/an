One file per PR: `<YYYY-MM-DD>-an<issue>-<slug>.md` holding the entry, one line starting `- ` (bold title, the issue, what changed; terse). A file no other PR touches, so parallel PRs never conflict. `python misc/changelog.py render` shows the changelog with the fragments in place; a maintainer folds them into `misc/CHANGELOG.md` with `python misc/changelog.py fold`. Details: `misc/changelog.py`. Entries within a date follow the file names (alphabetical, not merge order). A workflow (`.github/workflows/changelog-fold.yml`) folds the fragments into `misc/CHANGELOG.md` after each merge to the default branch.
