One file per PR: `<YYYY-MM-DD>-<slug>.md` holding the entry, one line starting `- ` (bold title, the issue, what changed; terse). A file no other PR touches, so parallel PRs never conflict. `python misc/changelog.py render` shows the changelog with the fragments in place; a maintainer folds them into `misc/CHANGELOG.md` with `python misc/changelog.py fold`. Details: `misc/changelog.py`.
